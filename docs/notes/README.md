# Working notes — not published

Personal notes, open questions and raw investigation logs. This directory is
**deleted before any public release** and is excluded from the built wheel.

Nothing here is a promise. Anything that turns out to be settled and generally
useful should be promoted:

- an explanation of a method, or how to read its output → `docs/explainers/`
- the reasoning behind a design choice → `docs/adr/`

Writing something in the wrong tier first costs nothing; `git mv` fixes it.
